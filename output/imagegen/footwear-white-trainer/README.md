# Footwear ecommerce preview set

Ten previews generated sequentially with the built-in `image_gen` tool. The fictional reference product is a consistent unbranded white leather low-top trainer with a natural gum rubber sole. Output 01 establishes its appearance.

Exact prompts and reference inputs: [prompts.json](prompts.json).

These are illustrative reference images. No source product photo was supplied, and the outsole and other newly revealed details are generated concepts rather than verified specifications. The two worn views show an adult model cropped below the knees. Copies of these ten files in `apps/web/public/output-examples/footwear/` supply the Ecommerce catalogue and selection-review thumbnails when a Footwear product is selected.
