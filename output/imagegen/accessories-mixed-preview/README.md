# Accessories ecommerce preview board

Open [index.html](index.html) to review ten reusable accessory shot styles. The board uses local PNGs, inline CSS and system fonts, so it works offline once the images are present. It has no JavaScript or application dependencies.

Each card carries the caption **“Example shown · adapts to your accessory”**. The pictured accessory illustrates the shot style; the reusable instruction applies to the selected accessory where relevant. Worn shots use its intended wearing position. **Reverse View requires a reference of the reverse surface.** Held Product Shot illustrates presentation in adult hands and does not promise accurate physical dimensions.

The fictional source assets are generated with the built-in `image_gen` tool. Exact prompts and reference inputs are recorded in [prompts.json](prompts.json). The board displays the original PNG files in 4:5 frames without editing or cropping their image content.

This is a standalone preview concept. It is not integrated into the application, and the captions do not indicate that automatic adaptation or a generation backend has been implemented. No app components, public assets or recipe definitions are changed by this preview board.
