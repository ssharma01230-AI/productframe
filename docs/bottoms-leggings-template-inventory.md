# Leggings template inventory

The Leggings family uses eight benchmark-mapped Ecommerce templates from
`apps/web/public/output-examples/bottoms/leggings/`. Template IDs are stable
and version 2.

| # | Stable template ID | Benchmark asset | Intended composition |
|---:|---|---|---|
| 01 | `ecommerce-bottoms-leggings-01` | `01-leggings.png` | Cropped straight front model |
| 02 | `ecommerce-bottoms-leggings-02` | `02-leggings.png` | Front flat-lay product |
| 03 | `ecommerce-bottoms-leggings-03` | `03-leggings.png` | Rear invisible mannequin |
| 04 | `ecommerce-bottoms-leggings-04` | `04-leggings.png` | Three-quarter front invisible mannequin |
| 05 | `ecommerce-bottoms-leggings-05` | `05-leggings.png` | Front invisible mannequin |
| 06 | `ecommerce-bottoms-leggings-06` | `06-leggings.png` | Folded top-down product |
| 07 | `ecommerce-bottoms-leggings-07` | `07-leggings.png` | Cropped rear model |
| 08 | `ecommerce-bottoms-leggings-08` | `08-leggings.png` | Full-length front model |

The benchmark pack presents women’s full-length fitted leggings in warm pale
cream-beige opaque matte stretch jersey, with a broad smooth high-rise waistband,
minimal tonal seams and narrow stitched ankle hems. It explicitly excludes
pockets, drawcords, ribbed cuffs, gathered waistbands and logos.
