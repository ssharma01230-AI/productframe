# Skirts template inventory

The Skirts family uses six benchmark-mapped Ecommerce templates from
`apps/web/public/output-examples/bottoms/skirts/`. Template IDs are stable and
version 2.

| # | Stable template ID | Benchmark asset | Intended composition |
|---:|---|---|---|
| 01 | `ecommerce-bottoms-skirts-01` | `01-skirt.png` | Close front product |
| 02 | `ecommerce-bottoms-skirts-02` | `02-skirt.png` | Close rear product |
| 03 | `ecommerce-bottoms-skirts-03` | `03-skirt.png` | Cropped front model |
| 04 | `ecommerce-bottoms-skirts-04` | `04-skirt.png` | Cropped rear model |
| 05 | `ecommerce-bottoms-skirts-05` | `05-skirt.png` | Full three-quarter model |
| 06 | `ecommerce-bottoms-skirts-06` | `06-skirt.png` | Full front natural model |

The benchmark pack shows a structured brown/taupe pleated skirt with a waistband,
belt loops, button and front-fly construction, vertical pleats/panels and a
flared hem. Model compositions use a fitted dark top and black ballet flats.
