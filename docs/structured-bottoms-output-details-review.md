# Structured Bottoms Output Details — visual review

Draft prompt text for review only. No application integration is included.

Scope: all 9 currently frontend-wired Ecommerce templates for the `structured_bottoms` family in `apps/web/app/studio/output-recipes.ts`. These are the subtype-specific image packs; the shared Lifestyle and Campaign recipes are outside this document. Slot ordering, IDs and asset references below match that mapping. Every referenced image was visually inspected.

The uploaded product remains authoritative for colour, material, length, fit and construction. Benchmark colours and features are not mandatory: do not add pockets, cords, pleats, closures or cuffs that the product does not have, or remove ones it does. Supporting tops and footwear are secondary styling. Where a pose uses pockets, use relaxed hands beside the garment if the product has none. Do not infer an unseen rear design from a front image.

The requested background is light warm beige, approximately #C8C1B6, replacing the benchmark's existing white/grey surface where necessary. This is draft output direction, not a claim that the image assets have been changed.

Review notes: this is the shared structured-bottoms pack (including its fallback use), not a separate image pack per trouser material. Slot 03 is visibly model-worn although its frontend name says Product. Slot 08 shows a pocket/waistband macro, not the centre closure mentioned in the current frontend description. The text below follows the images; no UI names or descriptions were changed.
