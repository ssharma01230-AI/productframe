# Shorts template inventory

The Shorts family uses nine benchmark-mapped Ecommerce templates from
`apps/web/public/output-examples/bottoms/shorts/`. Template IDs are stable and
version 2; there is intentionally no tenth pocket-detail template yet.

| # | Stable template ID | Benchmark asset | Intended composition |
|---:|---|---|---|
| 01 | `ecommerce-bottoms-shorts-01` | `01-flat-laid-product.png` | Complete shorts laid flat, product-only |
| 02 | `ecommerce-bottoms-shorts-02` | `02-front-invisible-mannequin.png` | Front product on invisible mannequin |
| 03 | `ecommerce-bottoms-shorts-03` | `03-three-quarter-invisible-mannequin.png` | Three-quarter product on invisible mannequin |
| 04 | `ecommerce-bottoms-shorts-04` | `04-rear-invisible-mannequin.png` | Rear product on invisible mannequin |
| 05 | `ecommerce-bottoms-shorts-05` | `05-front-facing-model.png` | Waist-down front-facing model |
| 06 | `ecommerce-bottoms-shorts-06` | `06-three-quarter-full-length-model.png` | Full-length three-quarter model, face excluded |
| 07 | `ecommerce-bottoms-shorts-07` | `07-rear-facing-model.png` | Waist-down rear-facing model |
| 08 | `ecommerce-bottoms-shorts-08` | `08-full-length-front-facing-model.png` | Full-length straight-on model, face excluded |
| 09 | `ecommerce-bottoms-shorts-09` | `09-waistband-closure-detail.png` | Waistband, drawcord, closure and upper-front detail |

The benchmark product is a navy textured casual short with an elastic waistband,
white drawcord and metal tips, slanted front pockets, front closure seam and
folded hems. Product references remain authoritative for identity; these images
control only composition and presentation.
