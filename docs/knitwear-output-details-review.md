# Knitwear — visually reviewed Output Details

Draft text only; no application code changed. All 11 currently wired Knitwear ecommerce benchmark assets were opened and visually inspected. Ordering and IDs follow `apps/web/app/studio/output-recipes.ts`. These are proposed output descriptions grounded in the images, not a claim that backend generation has been changed or validated.

Use the uploaded garment's identity, colour, material, pattern, construction and fit—not the benchmark's navy crewneck jumper. Construction details mentioned below apply only when supported by the uploaded product; do not invent pockets, drawstrings, ribbing, closures or underlayers that conceal its design. Exposed backgrounds use the warm beige direction of the existing Tops review documents (approximately #C8C1B6), rather than copying the assets' pale neutral backgrounds. Macro fabric remains the product's own colour.

Review note: slot 04 is currently named “Front Product”, but its image clearly shows a model with clasped hands. The section below follows that image. Several model images include a partial lower face; these crops are stated explicitly rather than incorrectly described as fully face-excluded.
